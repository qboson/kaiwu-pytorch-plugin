# 调参后的运行

两个在验证集上胜过参考运行的配置，之后**只在 100 张测试图上评估一次**。参考运行为 [`results/primary/`](../primary)（784-64-40，`β = 1`，测试准确率 38.3% ± 16.8%）。

## 流程

- **超参数只在验证集上选。** 验证集共 100 张、每类 10 张：取 MNIST 训练文件里每类第 101 到 110 张，与 1,000 张训练图不重叠（`--validation-per-class 10`）。
- 调参阶段从未读取测试集（`--skip-test`）。只有下面两个最终配置在 5 个 epoch 后、每个种子各评估测试集一次。
- 全部在 Kaiwu 1.4.1 上运行，与参考运行同版本。归档保留配置、汇总、各种子状态、测试指标，以及每个 epoch 的验证结果。参数快照和逐样本预测留在本地。
- 筛选用种子 0、3 个 epoch，每次只相对参考改一项；最好的几项用种子 1、2 复核，并加入叠加配置。

## 筛选（3 个 epoch 后的验证准确率）

只用种子 0，参考为 17%，平局率 59%：

| 改动 | 验证准确率 | 平局率 |
|---|---|---|
| `--init-gains 1,0.5` | 60% | 5% |
| `--beta 2` | 56% | 9% |
| 输出层学习率 ×0.5 | 50% | 19% |
| `--iterations-per-t 20` | 34% | 2% |
| `--candidate-count 16` | 17% | 59% |
| `--weight-decay 1e-4` | 18% | 63% |
| `--iterations-per-t 40` | 10% | 100%（全部预测为类 3） |
| `--beta 0.5` | 10% | 0%（全部预测为类 7） |
| 输出层学习率 ×2 | 10% | 100%（全预测同一类） |
| `--init-gains 1,2` | 10% | 100%（全预测同一类） |
| `--hidden-sizes 128` | 10% | 98%（全预测同一类） |
| `--hidden-sizes 128,64` | 9% | 78%（几乎全预测为类 9） |

失败的设置对每张图都预测同一个类，10% 就是随机水平。在这个训练长度下，更宽或更深的网络没有帮助。所有候选都是并行跑的单因素改动，而不是逐组贪心；“输出层 ×2 / ×0.5”同时缩放权重和偏置的学习率。

## 种子 0、1、2 复核（3 个 epoch 后的验证准确率）

| 配置 | 种子 0 | 种子 1 | 种子 2 | 均值 |
|---|---|---|---|---|
| 参考 | 17% | 50% | 32% | 33.0% |
| `--init-gains 1,0.5` | 60% | 51% | 63% | 58.0% |
| `--beta 2` | 56% | 53% | 49% | 52.7% |
| 两者叠加 | 54% | 57% | 56% | 55.7% |

三个配置在每个种子上都高于参考，不过 `--init-gains 1,0.5` 在种子 1 上只领先 1 个点。参考偏弱主要是种子 0 和种子 2 里平局很多的轮次，而这些改动消除了它们。

## 最终结果（5 个 epoch，测试集，仅一次）

| 配置 | 目录 | 测试准确率（均值 ± 标准差） | 各种子 | 平局率（均值） |
|---|---|---|---|---|
| `--init-gains 1,0.5` | [`gain05/`](gain05) | **62.7% ± 1.9%** | 60 / 64 / 64 | 6.7% |
| `--init-gains 1,0.5 --beta 2` | [`gain05-beta2/`](gain05-beta2) | **62.3% ± 6.6%** | 71 / 61 / 55 | 5.0% |
| 参考（`results/primary/`） | [`../primary/`](../primary) | 38.3% ± 16.8% | 15 / 54 / 46 | 28.7% |

标准差为三个种子的总体标准差。第 5 个 epoch 后的验证准确率：`gain05` 为 57.0%，`gain05-beta2` 为 55.3%。每个种子 10,100 次训练求解，外加 100 次测试和 500 次验证求解。逐 epoch 验证曲线在 `seeds/<s>/epochs/<e>/validation.json`。

## 怎么读这个结果

- 两个配置的测试准确率都比参考高约 24 个点，平局率从约 30% 降到 5% 到 7%。主要原因是平局变少，以及不再塌缩到同一个类。
- 两者之间没有有意义的胜负：均值只差 0.4 个点，远小于种子间的波动。`gain05` 只改一项、波动更小。
- 三个种子加 100 张测试图样本很小，一张图就是一个点。相对参考的优势可信，但两个调参配置之间的排名无法分出。
- 验证和测试曲线随 epoch 并不单调（例如 `gain05` 种子 0 的验证为 39、52、60、43、55%），所以最后一个 epoch 的结果有噪声。

## 复现

```powershell
python -m examples.mnist_kaiwu.experiment --output results/tuned/gain05 `
  --validation-per-class 10 --eval-every-epoch --init-gains 1,0.5
python -m examples.mnist_kaiwu.experiment --output results/tuned/gain05-beta2 `
  --validation-per-class 10 --eval-every-epoch --init-gains 1,0.5 --beta 2
```
