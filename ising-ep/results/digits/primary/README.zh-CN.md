# Digits 参考运行

[English](README.md) · [中文](README.zh-CN.md)

这是 sklearn Digits 上默认配置的三次种子运行，只读。调参后的运行在 [`../tuned/`](../tuned/README.zh-CN.md)。

不要覆盖这个目录。把 `--output` 指到新路径。

归档只保留 JSON。参数快照、翻转率和逐样本预测留在本地运行目录。

## 来源

2026-11-14 在 Kaiwu 1.4.1 上由当前代码产生（`config.json` 记录的时间是 `2026-11-13T18:05:57Z`）。命令：

```powershell
python -m examples.digits_kaiwu.experiment --output runs/digits-final/primary `
  --seeds 0,1,2 --epochs 5 --validation-fraction 0.2 --eval-every-epoch
```

划分种子用默认值 0：全部 1797 张按类别分层，测试集 360 张，再从训练部分切出 288 张做验证，实际训练 1149 张。测试集每个种子只评估一次。

## 主要数字

64-64-40，5 个 epoch，批大小 10，`lr = 0.01`，`β = 1.0`。标准差是三个种子的总体标准差。

| 种子 | 测试准确率 | 平局率 | 第 5 个 epoch 的验证准确率 |
|------|------------|--------|------------------------------|
| 0 | 0.0972 | 1.00 | 0.097 |
| 1 | 0.1028 | 1.00 | 0.101 |
| 2 | 0.1000 | 1.00 | 0.101 |
| **均值** | **0.1000 ± 0.0023** | 1.00 | 0.100 |

每个种子 13,290 次求解：训练 5,745 次自由相 + 5,745 次微扰相（1149 × 5 × 2），验证 1,440 次（288 × 5），测试 360 次。

测试集上每一张图都是平局，准确率就是随机水平。3 个 epoch 的筛选阶段里，这个配置也停在约 11%，并且把几乎所有验证图都判成同一个类。它没有学起来。

同一划分、同一训练预算的反向传播对照是 93.52% ± 0.65%，见 [`examples/digits_kaiwu/`](../../../examples/digits_kaiwu/README.zh-CN.md)。
