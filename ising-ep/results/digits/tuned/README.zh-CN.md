# Digits 调参后的运行

[English](README.md) · [中文](README.zh-CN.md)

两个在验证集上胜过参考运行的配置，之后**只在 360 张测试图上评估一次**。参考运行为 [`../primary/`](../primary/README.zh-CN.md)（64-64-40，`β = 1`，测试准确率 10.0% ± 0.2%，平局率 100%）。

## 流程

- **超参数只在验证集上选。** `--validation-fraction 0.2` 从训练部分分层切出 288 张，剩余 1149 张用于训练。划分种子是默认的 0，和反向传播对照相同。
- 筛选和复核都带 `--skip-test`，没有读测试集。只有下面两个最终配置在 5 个 epoch 后、每个种子各评估测试集一次。
- 全部在 Kaiwu 1.4.1 上运行。归档保留配置、汇总、各种子状态、测试指标，以及每个 epoch 的验证结果。参数快照和逐样本预测留在本地。
- 筛选用种子 0、3 个 epoch，每次只相对参考改一项。高于参考的两项用种子 1、2 复核，并加入两者的叠加。

## 筛选（种子 0，3 个 epoch 后的验证准确率）

参考为 10.1%，平局率 0%，几乎所有图都被判成同一个类：

| 改动 | 验证准确率 | 平局率 |
|---|---|---|
| 输出层学习率 ×0.5 | 50.0% | 6.2% |
| `--beta 2` | 41.3% | 5.2% |
| `--init-gains 1,0.5` | 12.2% | 0% |
| `--candidate-count 16` | 10.1% | 0% |
| `--weight-decay 1e-4` | 10.1% | 0% |
| `--iterations-per-t 20` | 10.1% | 0% |
| `--iterations-per-t 40` | 10.1% | 0% |
| `--init-gains 1,2` | 10.1% | 100% |
| `--beta 0.5` | 10.1% | 100% |
| `--hidden-sizes 128` | 10.1% | 100% |
| `--hidden-sizes 128,64` | 9.7% | 85.1% |
| 输出层学习率 ×2 | 9.7% | 100% |

“输出层 ×0.5 / ×2”同时缩放该层权重和偏置的学习率，也就是 `--lr-weights 0.01,0.005` 与 `--lr-biases 0.01,0.005`，或把 `0.005` 换成 `0.02`。`--init-gains 1,0.5` 的验证曲线是 41%、46%、12%：前两个 epoch 在上升，第三个 epoch 塌回同一个类，所以按最终 epoch 它没有入选。

## 种子 0、1、2 复核（3 个 epoch 后的验证准确率）

| 配置 | 种子 0 | 种子 1 | 种子 2 | 均值 |
|---|---|---|---|---|
| 参考 | 10.1% | 13.5% | 10.1% | 11.2% |
| 输出层学习率 ×0.5 | 50.0% | 42.4% | 45.1% | 45.8% |
| `--beta 2` | 41.3% | 39.9% | 33.0% | 38.1% |
| 两者叠加 | 42.0% | 49.7% | 46.2% | 45.9% |

两项单独的改动和它们的叠加，在每个种子上都高于参考。叠加与只改学习率的均值只差 0.1 个点。`--beta 2` 单独使用时每个种子都更高，但均值低约 8 个点，没有单独拿去跑测试集。

## 最终结果（5 个 epoch，测试集，仅一次）

| 配置 | 目录 | 测试准确率（均值 ± 标准差） | 各种子 | 平局率（均值） |
|---|---|---|---|---|
| 输出层学习率 ×0.5 | [`lrout05/`](lrout05) | **49.9% ± 1.3%** | 50.8 / 50.8 / 48.1 | 6.6% |
| 再加 `--beta 2` | [`lrout05-beta2/`](lrout05-beta2) | **49.3% ± 0.6%** | 48.6 / 49.2 / 50.0 | 5.0% |
| 参考 | [`../primary/`](../primary) | 10.0% ± 0.2% | 9.7 / 10.3 / 10.0 | 100% |

标准差为三个种子的总体标准差。第 5 个 epoch 后的验证准确率：`lrout05` 为 48.6%，`lrout05-beta2` 为 50.8%，参考为 10.0%。每个种子 11,490 次训练求解，外加 360 次测试和 1,440 次验证求解。

## 怎么读这个结果

- 两个配置的测试准确率都比参考高约 40 个点，平局率从 100% 降到 5% 到 7%。参考在 5 个 epoch 后对每张测试图都是平局。
- 两者之间没有有意义的胜负：均值只差 0.6 个点，小于 `lrout05` 各种子之间的差距。
- 同一划分、同样 5 个 epoch 的反向传播对照是 **93.52% ± 0.65%**。EP 低大约 44 个点。这个差距是结果的一部分，不是还没跑完。
- 验证曲线不单调。例如 `lrout05` 种子 1 的验证准确率是 29%、42%、42%、55%、48%，所以最后一个 epoch 的数字带噪声。

## 复现

```powershell
python -m examples.digits_kaiwu.experiment --output results/digits/tuned/lrout05 `
  --validation-fraction 0.2 --eval-every-epoch --seeds 0,1,2 `
  --lr-weights 0.01,0.005 --lr-biases 0.01,0.005
python -m examples.digits_kaiwu.experiment --output results/digits/tuned/lrout05-beta2 `
  --validation-fraction 0.2 --eval-every-epoch --seeds 0,1,2 `
  --lr-weights 0.01,0.005 --lr-biases 0.01,0.005 --beta 2
```
