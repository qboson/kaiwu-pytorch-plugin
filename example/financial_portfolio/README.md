# Quantum-Inspired Financial Portfolio Optimization (QUBO/Ising + RBM)

This example implements a complete, offline-reproducible **cardinality-constrained
Markowitz portfolio optimization** pipeline built with `kaiwu-pytorch-plugin`.
It formulates discrete asset selection ($\sum_i x_i = K$) as an exact QUBO
mapped to an Ising Hamiltonian via `kaiwu.torch_plugin._kaiwu_compat.qubo_matrix_to_ising_matrix`,
optionally enhances the empirical covariance matrix using joint market-regime
scenarios generated by `kaiwu.torch_plugin.RestrictedBoltzmannMachine`, and
benchmarks out-of-sample risk-adjusted performance against **Equal-Weight (`1/N`)**,
**Greedy Top-K Sharpe**, and **Exact Brute-Force Optimal** baselines under a
strict chronological (zero look-ahead) split.

## Problem Formulation

Given annualized training expected returns $\mu \in \mathbb{R}^N$, covariance
matrix $\Sigma \in \mathbb{R}^{N \times N}$, risk-aversion coefficient $\gamma \ge 0$,
and exact cardinality constraint $K \in \{1, \dots, N-1\}$ with equal weights
$w_i = x_i / K$ for binary selections $x \in \{0, 1\}^N$:

$$\min_{x \in \{0, 1\}^N} \;\; \frac{\gamma}{K^2} x^\top \Sigma x - \frac{1}{K} \mu^\top x + \lambda \left(\sum_{i=1}^N x_i - K\right)^2$$

Expanding the quadratic penalty with $x_i^2 = x_i$ yields the symmetric QUBO
objective $x^\top Q x + \lambda K^2$:

- $Q_{ii} = \frac{\gamma}{K^2} \Sigma_{ii} - \frac{1}{K} \mu_i + \lambda (1 - 2K)$
- $Q_{ij} = \frac{\gamma}{K^2} \Sigma_{ij} + \lambda \quad (i \neq j)$

The QUBO matrix $Q$ is converted to an $(N+1) \times (N+1)$ Ising matrix $J$
with constant bias $c$ through `qubo_matrix_to_ising_matrix(Q)` (compatible with
Kaiwu SDK 1.3.1, 1.4.0, and 1.4.3). For every binary state $x \in \{0, 1\}^N$
and both auxiliary spin polarities $s_{\text{aux}} \in \{-1, +1\}$ with
$s_i = s_{\text{aux}}(2x_i - 1)$:

$$x^\top Q x = -s^\top J s + c$$

In addition, `RBMScenarioEnhancer` fits a `RestrictedBoltzmannMachine` strictly
on binarized in-sample training return regimes via `rbm.sample(sampler)` and
`rbm.objective(s_pos, s_neg)`, then blends the RBM-implied correlation structure
with the empirical training covariance matrix for generative regularization.

## Dependencies

This example uses **only core `kaiwu-torch-plugin` dependencies** (`torch`,
`numpy`, `kaiwu`) and requires **zero external data downloads** in default mode.

```bash
pip install -r requirements/requirements.txt
pip install .
```

## Quick Start

Run the default offline 16-asset, $K=5$ benchmark (~2 seconds on CPU):

```bash
python example/financial_portfolio/run_portfolio.py
```

Quick smoke run (`--fast`) with structured JSON export:

```bash
python example/financial_portfolio/run_portfolio.py --fast --output-json /tmp/portfolio_results.json
```

Run on a local CSV file of asset returns (or prices with `--is-prices`):

```bash
python example/financial_portfolio/run_portfolio.py \
  --dataset csv \
  --data-path /path/to/returns.csv \
  --target-k 5 \
  --train-ratio 0.6
```

## Switching to Kaiwu SDK SA or Photonic Quantum CIM

`--sampler` switches the Ising backend for both QUBO optimization and RBM
sampling without modifying model code:

| `--sampler` | Backend | Requirements |
|---|---|---|
| `local_sa` (default) | `LocalIsingPortfolioSampler` (Metropolis-Hastings + Kawasaki polish) | Offline, no license required |
| `sa` | `kaiwu.classical.SimulatedAnnealingOptimizer` | Activated Kaiwu SDK license |
| `cim` | `kaiwu.cim.CIMOptimizer` + `PrecisionReducer` (`_kaiwu_compat`) | Activated Kaiwu SDK license + CIM QPU quota |

Example commands in licensed Kaiwu SDK / CIM environments (after calling
`kw.license.init(user_id, sdk_code)`):

```bash
# Kaiwu SDK Simulated Annealing
python example/financial_portfolio/run_portfolio.py --sampler sa

# Coherent Ising Machine (CIM) photonic quantum hardware
python example/financial_portfolio/run_portfolio.py \
  --sampler cim \
  --cim-task-name kpp_portfolio_qubo \
  --cim-task-mode optimization
```

See the repository root [README.md](../../README.md) for SDK authorization and
CIM real-machine quota details.

## Quantitative Benchmark Results

Measured on CPU with the default deterministic multi-sector synthetic market
(`--seed 42`, $N=16$ assets across 4 sectors, $K=5$, 302 training days / 202
out-of-sample future test days, $\gamma=2.5$, auto-calibrated $\lambda=0.3226$):

- **Verified QUBO-to-Ising max absolute discrepancy**: `9.770e-15` (across both
  auxiliary spin polarities $s_{\text{aux}} \in \{-1, +1\}$).

| Strategy | Ann. Return ↑ | Ann. Vol ↓ | Sharpe ↑ | MaxDD ↓ | Feasible | Opt. Gap ↓ | CPU Time |
|---|---:|---:|---:|---:|:---:|---:|---:|
| Equal-Weight (`1/N`, 16 assets) | 12.48% | 13.89% | 0.916 | 7.29% | YES | N/A | 0.000 s |
| Greedy Top-K Sharpe (`K=5`) | 4.65% | 23.09% | 0.312 | 17.96% | YES | 96.54% | 0.000 s |
| Exact Brute-Force (`K=5`, 4,368 subsets) | 11.52% | **13.77%** | 0.861 | 9.39% | YES | **0.00%** | 0.007 s |
| QUBO-Ising (`local_sa`, `K=5`) | 11.52% | **13.77%** | 0.861 | 9.39% | YES | **0.00%** | 0.020 s |
| QUBO-Ising + RBM (`local_sa`, `K=5`) | 11.52% | **13.77%** | 0.861 | 9.39% | YES | **0.00%** | 1.875 s |

Key observations:
- `QUBO-Ising (local_sa)` recovers the **exact global Markowitz optimum**
  (`0.00%` optimality gap) with `100%` cardinality feasibility in `0.020 s`.
- Compared with `Greedy Top-K Sharpe (K=5)` (which over-concentrates in a single
  high-correlation sector), `QUBO-Ising` reduces out-of-sample annualized
  volatility from `23.09%` to `13.77%` (**-40.4%**), cuts maximum drawdown from
  `17.96%` to `9.39%` (**-47.7%**), and raises out-of-sample Sharpe ratio from
  `0.312` to `0.861` (**+176.0%**).
- `QUBO-Ising + RBM` trains a `RestrictedBoltzmannMachine` strictly on training
  return regimes via `rbm.sample(sampler)` and confirms the same optimal
  diversified 5-asset portfolio.
